Heads-ups

Warned, never blocked.

Before an edit is written, Vibez checks who else is nearby: the same file or element, the same page, or a task described in similar words.

Handoffs

Pass it on, pick it up.

Hand a task, its next steps and its files to a teammate. They click Take over and carry on where you left off.

Shared notes

Leave a note on a file.

A decision or a gotcha pinned to a file is shown to every agent that starts working near it.

The language

A new way to write code.
Built on JavaScript.

Vibez apps are written in .vi, a language of blocks and wires. Every graph compiles into a real JavaScript function, so what you build runs like any other JavaScript.

unitPrice.vigraph

White wires: what happens next Coloured wires: the data

→
compiled JavaScriptsimplified
export async function unitPrice(total, count) {
  const price = total / count;
  console.log("Unit Price: " + price);
  return price;
}

Follow along: each block lights up the line it becomes.

Four kinds of thing

Page data a page shows, page actions it runs, functions you reuse, and variables they share.

Types you can read

Text, numbers, true or false, links, dates, objects and lists, each wire coloured by the kind of data it carries.

Pages meet logic by name

A button runs an action, a list repeats over data. The page only offers the links that fit.

Run and test one piece

Try a single function with your own inputs and watch its output in the console.
